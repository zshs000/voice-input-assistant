## 2. 项目目标

开发一个 Windows 桌面语音输入助手，帮助用户提高中文文本输入效率。

产品形态不是传统系统输入法 IME，而是桌面辅助工具：

```text
录音 -> 中文语音识别 -> 可选 AI 场景润色 -> 复制或自动插入文本
```

核心亮点是“场景化 AI 润色”。产品不只是语音转文字，而是把用户的自然口语转换成更适合使用场景的中文文本。

## 3. 已确认产品决策

- 应用形态：桌面语音输入助手
- 目标平台：Windows
- 技术栈：Tauri 2 + React + TypeScript + Recoil + Vite + Rust
- 语言范围：只做中文
- 录音方式：
  - 页面按钮：点击开始，再点结束
  - 快捷键：长按开始，松开结束
- 语音识别：
  - 先做录音结束后的非流式识别
  - 架构预留实时流式识别
  - 优先云端识别
  - 预留本地识别 Provider
- AI 润色：
  - 用户可以关闭润色，直接使用原文
  - 支持内置场景模板
  - 支持自定义提示词
  - LLM 先只实现 OpenAI-compatible API
  - 其他供应商只做架构预留
- 输出方式：
  - 复制到剪贴板
  - 自动插入当前光标位置
  - 用户可同时启用二者
- 历史记录：
  - 保存最近输入文本
  - 保存原始识别文本和最终输出文本
  - 不保存原始音频
