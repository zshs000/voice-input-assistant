# 语音输入助手产品设计

## 产品定位

语音输入助手是一款面向 Windows 桌面的轻量输入辅助工具。它不接入系统 IME，而是通过桌面窗口、全局快捷键、剪贴板和模拟粘贴，在常见应用中提供接近输入法的语音输入体验。

核心流程：

```text
录音 -> 中文语音识别 -> 可选 AI 润色 -> 复制或自动插入 -> 历史记录
```

产品重点不是单纯把语音转文字，而是把口语化输入整理成更适合当前场景的中文文本。

## 当前已实现能力

- 主窗口：录音入口、状态展示、模板选择、输出方式选择、结果编辑、最近历史。
- 小窗口/精简窗口：适合悬浮在桌面上快速开始或结束录音。
- 全局快捷键：支持切换模式和按住说话模式。
- 语音识别：
  - DashScope Qwen-ASR Realtime WebSocket 路径。
  - Mock 模式用于无外部服务时演示流程。
- 录音采集：浏览器麦克风采集 16 kHz PCM，分块发送到 Tauri 后端。
- AI 润色：OpenAI-compatible Chat Completions。
- 输出方式：
  - 仅复制到剪贴板。
  - 自动插入目标窗口。
  - 复制并插入。
- 自定义模板：用户可新增、编辑、删除带 `{{input}}` 占位符的提示词。
- 本地数据：
  - 设置保存到本地 JSON。
  - 历史记录只保存文本，不保存原始音频。

## 用户场景

- 聊天软件中快速输入自然中文消息。
- 邮件、报告、作业等场景中把口语转成正式表达。
- 会议或课堂后快速整理要点。
- 内容创作时把零散口述整理成可发布草稿。

## 模板体验

内置模板包括：

- 原文模式：跳过 LLM，直接输出识别文本。
- 去除口语：删除口头禅、重复和停顿词。
- 正式表达：改写为正式、清晰的书面中文。
- 简洁表达：压缩冗余内容，保留核心意思。
- 聊天表达：改写为自然、轻松的日常聊天语气。
- 会议/课堂要点：整理为条目。

自定义模板允许用户把固定写作风格、平台风格或专业场景沉淀成自己的提示词。

## 输出策略

复制是最稳定的兜底输出方式。自动插入依赖 Windows 焦点切换和目标应用输入行为，失败时仍应保证结果已经复制到剪贴板，避免用户丢失文本。

## 设置项

- STT Provider：DashScope 或 Mock。
- DashScope API Key、endpoint、model、language。
- LLM Base URL、API Key、model、temperature。
- 默认模板和输出方式。
- 全局快捷键与快捷键模式。
- 小窗口是否置顶。

## 已知产品限制

- DashScope 识别依赖桌面 Tauri 运行环境和有效 API Key；浏览器开发模式主要用于 UI 和逻辑调试。
- 自动插入不是系统 IME，可能受目标软件、权限、焦点和安全策略影响。
- 当前历史记录保存最近文本结果，不做搜索、标签和多设备同步。
- 没有账号系统、云同步、模板市场或本地语音模型。

## 后续方向

- 将首次启动体验改为更明确的“配置 DashScope 或切换 Mock”引导。
- 增加托盘入口和更完整的窗口生命周期管理。
- 补充真实服务 smoke test 与失败诊断页面。
- 扩展本地 STT、术语词库和多模型协议适配。
